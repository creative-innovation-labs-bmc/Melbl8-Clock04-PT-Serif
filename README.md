# Melbourne Typewriter Clock — PT Serif

An independent 3840 × 804 natural-language clock for Enplug and NVIDIA Shield signage.

## Typography

- Animated clock sentence: **PT Serif Bold**
- Footer, date, location and status: **Open Sans**

Both families are loaded through the official Google Fonts CSS API and are distributed under the SIL Open Font License.

## Production

- Live Melbourne time
- Single-line layout only
- Aurecon Green time phrase: `#89C925`
- Smooth deletion-time scaling
- Automatic viewport scaling for mobile testing
- `noindex`, `nofollow`, `noarchive`, `nosnippet`, `noimageindex`
- `robots.txt` blocks all crawlers
